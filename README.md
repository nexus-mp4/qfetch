# qfetch
CLI tool made in C for displaying a random quote from [Quotable API](https://github.com/lukepeavey/quotable).

__Yes this is very crappy, I know. Everybody starts out *somewhere*.__

---

### dependencies:
- cjson
- curl

---

### installation:
#### Linux :
```
git clone https://nexus-mp4/qfetch
cd qfetch
sudo make install
```
#### macOS :
```
git clone https://nexus-mp4/qfetch
cd qfetch
sudo make install_mac
```
